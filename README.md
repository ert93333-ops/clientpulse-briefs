# ClientPulse Briefs

ClientPulse Briefs turns rough project notes into a client-ready weekly status update for agencies, consultants, fractional marketers, and freelancers.

Public MVP: https://ert93333-ops.github.io/clientpulse-briefs/

## What it does

- Paste rough notes from client work
- Generate a structured weekly update with wins, progress, risks, next steps, and client asks
- Reserve early access with plan and purchase-intent fields

## Who it is for

- Small agency owners
- Account managers
- Fractional marketers
- Consultants and freelancers sending recurring client updates

## Pricing hypothesis

- Solo: $15/month
- Agency: $39/month
